# Phase 1 reference matrix

All ten inputs are original 864 × 1536 PNGs from the verified bundle. Pixel inspection excludes the outer handset shell, mock camera, external light streaks and simulated Android bars. The common working crop is approximately **x=78–786, y=76–1458** (708 × 1382; 0.512 width/height). The horizontal mask intentionally excludes curved glass and rim highlights; bounds are shared alignment guides, not assertions of exact device geometry.

Approximate reference vertical anchors in source pixels. Slight overlap between hero artwork and the heading is intentional. Panel edges are rounded and glows extend beyond these coordinates.
