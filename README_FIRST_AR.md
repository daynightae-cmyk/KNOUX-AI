KNOUX AI — Codex Phase-1 Visual Implementation Kit

1. استخرج محتوى ZIP في مجلد مؤقت يسهل العثور عليه على ويندوز (أو فكّه داخل D:\KNOUX-AI لو مسار جديد تماماً).
2. افتح Codex على الكمبيوتر في بيئة لديها وصول فعلي إلى D: و Android SDK و Emulator.
3. أرفق ملفات الصور العشر من design/reference أو اجعلها في مساحة العمل.
4. انسخ نص MASTER_PROMPT_CODEX_PHASE_1_UI.md بالكامل إلى Codex.
5. البرومبت يأمر الوكيل بإنشاء D:\KNOUX-AI، وبناء UI للشاشات العشر والتقاط الصور واختبارها، ثم إيقاف التنفيذ قبل خدمات الـEnd-to-End.
6. تنبيه: لا تسمح للموديل بالادعاء أنه عمل على D: إذا كان يعمل داخل Cloud لا يصل إلى الكمبيوتر.
7. لا تعرض نتائج التصميم مثل 12.6GB أو 18% على أنها حقيقية. هي أرقام مرجعية للعرض فقط.
8. التنظيف الآمن في البرومبت يقتصر على المخرجات المؤقتة المثبت أنها غير فريدة وداخل نطاق المشروع. لا يحذف فروعاً أو worktrees أو SDK أو مشاريع أخرى دون موافقة صريحة.
