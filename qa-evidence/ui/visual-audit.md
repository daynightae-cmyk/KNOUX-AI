# Phase 1 visual QA

Ten source PNGs were individually opened and inspected. Ten final runtime frames were captured from `com.knoux.ai/.MainActivity` on `emulator-5554`, AVD `kx_preview`, Android 8.0 / API 26, x86_64. The capture script verified the foreground activity and matching Compose screen tag through Android UI Automator before every screenshot. Build: debug, English, portrait, 420 dpi, logical 1080 × 2340 (~411 × 891 dp). The API 26 emulator produced physical 1080 × 1920 screencaps with 97 px bars at both sides; the original display settings were restored. Decorative motion was frozen for reference capture only.

The [reference matrix](../../docs/visual/reference-matrix.md) records source geometry. Comparison strips exclude the reference handset and mock system bars; they remove x=0–96/983–1079 and about 52 px top/104 px bottom from the Android frame. Both interiors are scaled to 540 px wide without vertical stretching. The [RGB deltas](comparison-metrics.txt) are descriptive pixel differences, not a visual acceptance score.

All ten are implemented, run on the emulator, captured and visually compared. The second pass fixed tab captions, selected-tab styling, button clipping, Home card spacing, icon colors and stale-frame detection. The third pass (post-splash) traced the exact brand K into all glyphs and the Home orb, added orb rim light/bloom and a specular highlight, raised and brightened the particle-wave crest, converted icon badges to glowing rounded squares, thickened progress rings, brightened inactive glass rims, enlarged the topbar wordmark and switched Battery action pills to outlined cyan. All ten top-of-screen captures and the nine scrolled captures were refreshed after this pass with UI-hierarchy verification. The first candidate batch is retained separately and is not the reviewed capture set.

Final capture refresh: after a splash-only change that pauses the hidden Home decorative animation while the opaque brand overlay is visible, all ten top captures and the nine scrolled captures were re-taken on the same emulator with UI Automator tag checks before each shot. The comparison metrics are unchanged, confirming no screen-level visual regression. Splash evidence lives in `qa-evidence/splash/`; the emulator is software-rendered (SwiftShader), so motion smoothness is recorded as an environment limitation, not a visual pass.

The remaining cross-screen differences are the reference's larger, more detailed hero artwork (plasma filaments, filled-glow tile icons), some condensed/wrapped copy, and touch-friendly row spacing. The fixed Design preview chip and Android system bars are intentional. Approval of visual fidelity is pending owner review. No score here substitutes for that review.
