## Implemented

- `ResidueRules` — filename-evidence taxonomy only: `.trashed-`/`.pending-` are STRONG,
  generic leftovers (`.tmp`, `.part`, `.bak`, `~`, `.log`, thumbnails) are WEAK, and KNOUX's own
  cache is OWNED. Shared candidates must match a pattern **and** be at least the configured age;
  an unknown modification time disqualifies them. Only OWNED files can ever be bulk-selected.
- `ResidueRepository` — measures the app's own cache, MediaStore images/video (with the current
  grant) and explicitly granted SAF trees. It collapses aliases of one physical file, honours an
  excluded-URI set, and reports a PARTIAL status whenever a source could not be read.
- `ResidueController` — persists append-only passes, items, decisions and SAF profiles in Room v3;
  records `REVIEWED`, `DRY_RUN`, `SKIPPED`, `ATTEMPTED`, `VERIFIED`; executes local removal through
  the already-verified `SmartCleanController` path; re-queries the provider afterwards and drops
  only URIs that the operation actually verified.
- `ResidueReal` — measured Compose screen replacing the design-preview studio. The hero total is
  the persisted measurement, or an explicit dash before the first pass; a restored pass is labelled
  "PREVIOUS PASS — SCAN AGAIN TO VERIFY". Nothing is pre-selected in shared folders, and permanent
  deletion requires the irreversible acknowledgement.
- Room `2 → 3` additive migration, four new tables (`residue_scans`, `residue_items`,
  `residue_decisions`, `residue_profiles`) and the exported schema.

## Independent-review guarantees proven by tests

1. **No bulk selection outside our own cache.** `safeSelection` contains OWNED items only, even
   when shared evidence is STRONG (`safeSelectionContainsOwnCacheOnlyEvenWhenSharedEvidenceIsStrong`).
2. **A forged candidate cannot escape.** A candidate whose URI points outside the allowed cache
   roots is refused and the file is left untouched
   (`forgedCandidateOutsideTheCacheIsRefusedWithoutTouchingTheFile`), and a token without
   confirmation or irreversible acknowledgement deletes nothing
   (`unconfirmedOrUnacknowledgedPlansDeleteNothing`).
3. **Only verified removals leave the stored pass.** The UI case deletes one selected `.tmp`
   fixture, proves the unselected keeper still exists, and reads the persisted total drop back
   through Room. The DB inspection below shows the exact journal.
4. **Schema history survives.** `ResidueMigrationTest` opens a version-2 database, runs the real
   migration and asserts the prior operation history is intact while the residue tables appear.
5. **A fresh pass lists existing files only.** `ResidueFreshPassTest` performs a real pass over
   the device state and verifies every listed URI still exists inside the measured scope.
