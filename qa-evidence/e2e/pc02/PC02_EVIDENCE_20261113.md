## Implemented

- `DuplicateRules` — grouping by full-content SHA-256, mandatory keeper selection,
  `distinctPhysicalFiles()` alias collapse, defensive member dedupe.
- `DuplicateRepository` — real sources only: app-owned cache, MediaStore images/video and
  granted SAF trees. Aliases are collapsed before size bucketing and hashing, so one physical
  file seen through MediaStore and SAF is never treated as two copies.
- `DuplicateController` — persisted scan passes/groups/members, keep-forever exclusions,
  trash and permanent-delete plans through the real provider, verified after-state, Room
  history, interrupted-operation recovery before removal reconciliation.
- `DuplicateReal` — measured Compose screen replacing the design-preview studio. Counts,
  sizes, hashes and outcomes come from measured Room/provider data; the protected original
  can never enter a removal plan.
- Room v2 migration and DAO evidence tables: `duplicate_scans`, `duplicate_groups`,
  `duplicate_members`.

## Independent-review findings addressed

1. **Same physical file as MediaStore + SAF alias (blocking).**
   `FileCandidate.physicalKey` now records a best-effort physical identity (MediaStore volume +
   relative path + name; SAF external-storage document id; canonical cache path).
   `DuplicateRules.distinctPhysicalFiles()` prefers the MediaStore row and
   `DuplicateRepository.scan()` collapses aliases before bucketing and hashing. Regression
   tests: `mediaAndSafAliasesOfOneFileAreNeverTwoCopies`,
   `distinctPhysicalFilesWithTheSameContentStillFormARealGroup`.
2. **False consent copy (blocking).**
   The review sheet now distinguishes mixed selections (`hasLocalCopies && hasSharedMedia`) from
   shared-only and local-only selections. For mixed selections it states that KNOUX cache copies
   are deleted immediately while Android's dialog covers only shared media; for shared-only it
   states that cancelling the Android dialog removes nothing. `DuplicateReal.kt:1001-1018`.

Also corrected while verifying: recovery now runs before removal reconciliation on process
death; cancelling a scan reloads the last persisted measured pass instead of reporting that no
pass exists; the scan progress label reads "files inspected" (not "files read").

Test-only debt repaired: `AuthGatewayTest` no longer depends on the removed `auth-fingerprint`
tag or first-run/English state (`createEmptyComposeRule` + pinned `knoux.preview.english`,
onboarding preference saved/restored). No product behaviour was weakened.
